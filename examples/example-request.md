# Example requests

Start the workflow without supplying a subject:

```text
Create a one-minute historical documentary.
```

The agent must ask you for the historical topic and wait for your answer before beginning research or production.

Provide a subject:

```text
Create a one-minute historical documentary about the construction of the Roman Colosseum.
```

The agent should use Ethan Sterling unless another voice is explicitly requested, work in Landscape 16:9, synchronize historically accurate silent scenes with the completed narration, save the project using only the topic name, and leave it open for review.
